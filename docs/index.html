Silhouettes are placeholders on this page. HexDex shows each Pokémon's real artwork, including shiny versions, downloaded once and cached on your computer.

Reads, never writes

HexDex opens your exported files read-only. It does not edit them, and it does not open complete game saves.

Stays on your computer

No accounts, telemetry or analytics. Notes and tags stay in a local folder. It goes online only for data and artwork not yet cached (PokéAPI, GitHub), when you check for updates, and for Serebii links you select.

Game Boy to 3DS

One grid for .pk1 through .pk7 files. Gen 1 DVs and Gen 7 IVs sit side by side.

Every file, read in full

Select a card to see what the file holds. These panels run the same layouts as the app, with sample data.

Stats as a shape

Six base stats form a hexagon in the Pokémon's type colour. Beside it, the calculated stats use the file's own level, nature, IVs and EVs.

Search and filter
Name or nickname, type, generation, tags, favourites, shiny, legendary and eggs.

      
Sort
By Pokédex number, level, name, or shiny first.

      
Full stat detail
IVs or DVs, EVs, nature, calculated stats and trainer details.

      
Moves
Type, power and effect for each move, with tooltips.

      
Variant tabs
Several files of one species and generation share one card.

      
Notes and tags
Saved automatically for each file. Tag many Pokémon at once with Select.

      
Subfolders
Scan one folder or a whole tree of exports.

      
CSV export
Details, stats, moves, notes and tags in one spreadsheet.

      
Offline once cached
Data and artwork are kept locally after the first download.

      
Serebii links
Open the right generation's Serebii page for any Pokémon.

      
Light and dark
Follows your system appearance.

      
Update check
Select the version label to ask GitHub for a newer release. Never automatic.
